# Face Detection with OpenCV

A Python-based face detection project using OpenCV to detect faces in images and real-time video streams.

## Technologies Used

- Python
- OpenCV
- Haar Cascade Classifier

## Features

- Detects human faces using OpenCV
- Supports real-time face detection through a webcam
- Uses Haar Cascade for face detection

## How to Run

1. Install Python.
2. Install OpenCV:
   `pip install opencv-python`
3. Run the Python file.
4. Allow webcam access if required.

## Project Overview

This project demonstrates the basic implementation of face detection using Python and OpenCV. It uses a pre-trained Haar Cascade classifier to identify human faces from images or live webcam input.
